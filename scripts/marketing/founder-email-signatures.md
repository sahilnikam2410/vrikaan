## INSTALL — once per signature, takes 90 sec

### Gmail web

1. Gmail → ⚙️ Settings → **See all settings** → **General** tab
2. Scroll to **Signature** → click **+ Create new**
3. Name it `VRIKAAN founder`
4. Click **rich-text "T"** in toolbar to ensure rich mode
5. **Copy the HTML below** as rendered text (NOT source) — paste using a trick:
   - Open the HTML preview from the `.html` file Sahil saves locally → select all → Ctrl+C → paste into Gmail
   - OR open https://htmlsig.com/preview → paste raw HTML → copy rendered → paste in Gmail
6. Scroll to **Signature defaults** → set new sig for both `NEW EMAILS USE` and `ON REPLY/FORWARD USE`
7. **Save Changes**

### Apple Mail

1. Mail → **Preferences → Signatures**
2. Drag your VRIKAAN signature image to the preview pane (if avatar version)
3. OR uncheck "Always match my default message font" → paste HTML manually

### Outlook desktop

1. File → Options → Mail → **Signatures**
2. Paste HTML (rich-text mode)
3. Set default for "New messages" + "Replies/forwards"

## ⚙️ HOW TO COPY-PASTE THE HTML INTO GMAIL (the tricky bit)

Gmail's signature editor does NOT accept raw HTML directly. You need to paste **rendered HTML**. Easiest method:

### Method A — local file (recommended)

1. Save the HTML block as `sahil-signature.html` on your desktop
2. Double-click → opens in Chrome/Edge/Brave
3. Select all on the page (Ctrl+A) → Copy (Ctrl+C)
4. Switch to Gmail Signature settings → paste in editor (Ctrl+V)
5. Gmail preserves formatting

### Method B — paste-helper website

1. Go to https://htmlsig.com/preview or https://signature-generator.com
2. Paste raw HTML → it renders
3. Select all rendered → Copy → paste into Gmail

### Method C — Outlook Web

1. Use Outlook web first → paste HTML into Outlook signature (Outlook accepts raw HTML)
2. Send a test email to yourself in Gmail
3. Forward that email → use the rendered signature from there in Gmail
