## Tweet 2 — Pattern #1: Fake delivery SMS
```
1/ "Your parcel is held. Pay ₹25 customs:" → link.

Real couriers never SMS payment links. They use IVR or app push.

Defense:
• Long-press link → "Copy" not "Open"
• Paste into urlscan.io
• If domain isn't dtdc/delhivery/bluedart → block sender
```
